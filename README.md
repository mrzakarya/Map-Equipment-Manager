# سامانه مدیریت و پایش تجهیزات روی نقشه

یک برنامه تحت وب مبتنی بر **HTML، CSS، JavaScript و Leaflet** برای ثبت، نمایش، جستجو، ویرایش و مدیریت تجهیزات و نقاط روی نقشه جغرافیایی.

## امکانات

- نمایش نقشه ماهواره‌ای و خیابانی
- ثبت تجهیزات در مختصات دلخواه روی نقشه
- پشتیبانی از انواع نمادها: کشتی، هواپیما، جنگنده، آواکس، قایق، رادار، قطار، خودرو، کامیون، ایستگاه هواشناسی، خانه و نشانگر عمومی
- تولید شناسه خودکار برای تجهیزات
- ویرایش، حذف و جابه‌جایی نشانگرها
- جستجو و فیلتر تجهیزات بر اساس عنوان، شناسه و نوع
- اندازه‌گیری فاصله بین نقاط و محاسبه مساحت چندضلعی
- ذخیره اطلاعات در حافظه محلی مرورگر (LocalStorage)
- ورود و خروجی گرفتن از اطلاعات در قالب JSON
- پنل مدیریت قابل جمع‌شدن و جابه‌جایی
- رابط کاربری فارسی و راست‌چین

## اجرای برنامه

این پروژه در حال حاضر یک برنامه استاتیک است و به نصب Node.js یا راه‌اندازی سرور سمت سرور نیاز ندارد.

1. مخزن را دانلود یا Clone کنید.
2. فایل `index.html` را با مرورگر باز کنید.
3. برای دریافت نقشه و آیکون‌ها، اتصال اینترنت لازم است؛ زیرا کتابخانه‌ها و نقشه‌ها از سرویس‌های خارجی بارگذاری می‌شوند.

برای اجرای محلی با یک وب‌سرور ساده نیز می‌توانید از افزونه **Live Server** در Visual Studio Code استفاده کنید.

## راهنمای استفاده

1. روی نقشه کلیک کنید یا دکمه «افزودن تجهیز» را بزنید.
2. نوع تجهیز، عنوان و مختصات را تعیین و ذخیره کنید.
3. از پنل سمت راست برای جستجو، فیلتر، ویرایش و حذف تجهیزات استفاده کنید.
4. برای جابه‌جایی نشانگرها، ابتدا حالت «جابه‌جایی آیکون‌ها» را فعال کنید.
5. برای اندازه‌گیری، حالت «اندازه‌گیری» را فعال کرده و نقاط را روی نقشه انتخاب کنید.
6. با «بستن مساحت» چندضلعی را ببندید.
7. برای نگهداری یا انتقال اطلاعات، از خروجی و ورودی JSON استفاده کنید.

## نکات مهم

- اطلاعات `LocalStorage` فقط در همان مرورگر و همان مبدأ (Origin) ذخیره می‌شود. انتشار برنامه در GitHub اطلاعات کاربران را به‌صورت مشترک ذخیره نمی‌کند.
- خروجی JSON برای انتقال یا تهیه نسخه پشتیبان از داده‌ها در نظر گرفته شده است.
- نمایش نقشه و آیکون‌ها به سرویس‌های خارجی وابسته است و ممکن است با محدودیت دسترسی یا تغییر سیاست سرویس‌دهندگان مواجه شود.
- پیش از انتشار عمومی یا استفاده عملیاتی، شرایط استفاده و الزامات انتساب (Attribution) سرویس نقشه انتخاب‌شده را بررسی کنید. استفاده از کاشی‌های Google Maps باید با شرایط و مجوزهای مربوط به Google Maps Platform سازگار باشد.
- این نسخه فاقد سرور، حساب کاربری، پایگاه داده مشترک و همگام‌سازی بین دستگاه‌ها است.
